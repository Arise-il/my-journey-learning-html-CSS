# my-journey-learning-html-CSS

This project was my hands-on practice for learning the fundamentals of HTML and CSS — from basic tags all the way to responsive layouts with Flexbox and Grid.

## 🛠️ Built With

- HTML
- CSS

## 📚 What I Learned

Here's a breakdown of everything I picked up from the course, organized by topic.

### HTML Basics
- Elements, tags, and syntax (opening/closing tags, whitespace rules)
- Attributes (e.g. `href`, `target="_blank"`)
- The overall HTML structure: `<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`
- Head elements: `<title>`, `<link>` (for stylesheets and Google Fonts)
- Filepaths for linking files and folders
- Images: `<img>`, `src`
- Inputs: `<input type="text">`, `<input type="checkbox">`, `placeholder`
- The `<div>` container element and nesting
- Text/inline elements: `<strong>`, `<u>`, `<span>`, `<a>`
- Semantic elements: `<header>`, `<nav>`, `<main>`, `<section>`
- HTML comments (`<!-- -->`)

### CSS Basics
- Writing CSS with the `<style>` tag and external stylesheets
- Core properties: `background-color`, `color`, `height`, `width`, `border`, `border-radius`, `cursor`
- CSS values: color names, RGB, RGBA, Hex
- Measurement units: `px`, `%`, `em`, `rem`
- The `class` attribute and class-based selectors
- Pseudo-classes: `:hover`, `:active`
- Inline CSS styles
- CSS comments (`/* */`)

### Layout & Box Model
- The CSS Box Model: margin, padding, border
- Margin & padding shorthand values
- `display`: `block`, `inline-block`, `inline`
- The "nested layouts" technique (vertical/horizontal layout combinations)

### Flexbox & Grid
- `display: flex` — `flex-direction`, `justify-content`, `align-items`
- `flex`, `flex-shrink`
- `display: grid` — `grid-template-columns`, `column-gap`, `row-gap`, `fr` units
- Aligning grid items with `justify-content` and `align-items`

### Positioning
- `position: static`, `fixed`, `absolute`, `relative`
- Positioning with `top`, `bottom`, `left`, `right`
- Nesting `absolute` elements inside `fixed`/`relative` parents
- `z-index` and stacking order

### Text & Typography
- `font-family` and font stacks
- `font-size`, `font-weight`, `font-style`
- `text-align`, `line-height`, `text-decoration`
- Resetting default margins on `<p>` elements
- Loading custom fonts from Google Fonts

### Responsive Design
- Media queries: `@media (max-width: ...)`, `(min-width: ...)`
- Building layouts that adapt across screen sizes

### Advanced CSS
- Grouping selectors with commas and descendant selectors with spaces
- CSS inheritance
- CSS specificity rules
- Transitions: `transition: <property> <duration>`
- `opacity` and `box-shadow`
- Other useful properties: `object-fit`, `object-position`, `pointer-events`, `white-space`

### Tools
- Using Chrome DevTools to inspect and debug HTML/CSS live in the browser
